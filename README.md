A faster drop-in for makefun-diff 1.0.0: `solve.js` returns byte-identical patches for `{ old, new }` texts, but runs the Myers greedy search on interned integer line ids with typed-array V rows and a compact trace, instead of the reference's per-step path objects and string comparisons.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
